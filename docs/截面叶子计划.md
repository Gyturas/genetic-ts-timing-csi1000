# 截面结构叶子 · 注入指数择时挖矿 · 计划 v0(2026-07-30,待用户改进)

动机:指数 edge 的物理来源是成分股聚合微观结构(lead-lag/欠反应),但现有 9 叶子全是
指数自身量价——聚合把截面信息压扁了。个股面板在手,把截面状态做成**日频指数级序列**
当新叶子,是唯一还没动用的正交信息源。交易标的:**512100 ETF 直接**(等权线冻结)。

## 一、首批 4 个叶子(机制各管一摊,刻意克制数量)

| 叶子 | 定义(每日,池内截面) | 机制 |
|---|---|---|
| **宽度 breadth** | 上涨家数 / 有效家数 | 参与度:窄涨 vs 普涨的延续性不同,lead-lag 扩散的直接读数 |
| **离散度 disp** | 当日收益的截面标准差 | 分歧强度:高离散=lead-lag 活跃/情绪分化,动量-反转切换的状态变量 |
| **涨停温度计 limit_net** | (涨停家数 − 跌停家数)/ 有效家数 | A股特色情绪极值:连板潮=散户狂热,跌停潮=流动性挤兑 |
| **新高新低差 nhnl** | (250日新高 − 新低家数)/ 有效家数 | 慢参与度:长周期版宽度,GP 无法从指数价格自行构造 |
| **截面偏度 xskew** | 当日池内收益的截面偏度(三阶矩) | 妖股彩票日(右偏:少数暴涨+普跌)vs 闪崩日(左偏);散户彩票需求代理,与离散度(二阶)正交 |
| **成交额熵 amt_ent** | 池内成交额分布的香农熵(归一化) | 资金集中度:低熵=钱挤在少数票(题材末期),高熵=雨露均沾;熵版 HHI,比 HHI 平滑 |

**时序组补充(全资产原生,不用广播)**:**skew120** = 各指数自身收益的 120 日滚动偏度
——entropy120 的三阶矩兄弟,GP 的 26 算子拼不出偏度,和 entropy120 同机器造,零额外成本。

明确不加的(防共线):截面峰度(与偏度+离散度高度共线)、收益分布熵(与离散度重叠)、
HHI(被成交额熵替代)。二批候选压缩为:池内换手中位数、站上MA20比例。
**叶子 9 → 16(截面6广播 + skew120原生),数量超出原纪律——由预检残差IC关卡逐个杀,
过不了线的不进挖矿,实际入选数由数据说话。**

## 二、构造细则(都是这周踩过的坑)

1. **停牌剔除**:vol==0 或价格 NaN 的股票当日不进分子分母(否则假 0 收益压低离散度、污染宽度)
2. **涨跌停判定分板块分年代**:主板 ±9.5% 阈,创业板/科创板 2020-08-24 后 ±19.5%(按代码前缀 300/301/688 区分)
3. **池 point-in-time**:t 日用 t−1 日成分(与等权篮子同法);
   **2014-11 前无成分数据 → 代理池**:流通市值 = amount/(turn/100)(免复权、单位自洽),
   每月末全 A 排名取 801–1800 名。拼接日做连续性检查并披露
4. **因果性**:叶子只用当日及以前数据,信号仍收盘产生,无未来函数
5. 叶子进 GP 后走 rolling-rank 变换,天然免疫水平漂移

## 三、接入方式(两个方案)

- **方案 A(首选,零引擎改动)**:4 叶子作为"市场结构状态"**广播到 6 列**面板
  (小盘结构状态对全 A 股指有溢出效应,经济上站得住);类库/专属库照常挖
- 方案 B(备用,若 A 污染类库):双 TERMINALS——新叶子仅进专属 zz1000 库(需小改引擎)

## 四、预检门槛(先花 2 小时,不过关不开 pod)

1. 构造 4 序列(2005 起,含代理池段),拼接连续性 + 与现有叶子相关矩阵(正交性)
2. 每叶子 → rank40 等简单变换 → 对 Y=open 前瞻(h1/h5)的月度 IC(2015 起)
3. **残差 IC 关卡(生死线)**:对现有 h1+h5 合成信号回归取残差,残差月度 IC ≥ 0.01
   (与引擎入库残差线同标准)——证明是新信息,不是波动族换皮
4. **裁决:≥2 个叶子过残差线 → 开挖;全灭 → 判负归档,省一晚 pod**

## 五、挖矿与判定(预检通过后)

- TERMINALS 9→13,26 算子与全部制度不动;h∈{1,5} × 种子{42,137} = 4 库,pod 一晚
- 对照:同种子旧叶子四库。判定标准:**新四库合奏 vs 旧四库合奏(30.8%/1.60),
  年化或夏普一边显著改善且另一边不劣化**;同时检查新叶子因子的入库数与权重占比
  (真被进化选中了吗),以及后半程(2022+)是否同步改善
- 通过 → 併入 v5 候选;不过 → 归档,叶子留作研究素材

**裁决**:①不宣布新叶子胜出(尊重预注册);②新四库不弃——与旧四库并入**八库大合奏**
