# 运维手册

## 每日流程(自动)

launchd 任务 `com.gyturas.csi1000.daily.plist`,工作日 **16:30** 触发:

```
更新行情(13标的)→ 重算定稿信号(约2分钟)→ 生成桌面 HTML 面板 → 打印明日仓位
```

日志:`logs/daily.log`。配置备份:`scripts/生产/com.gyturas.csi1000.daily.plist`。

手动跑一次:
```bash
export PYTHONPATH=src
python -m csi1000.engine.daily_dashboard      # 全流程(会弹浏览器)
CSI1000_NO_OPEN=1 python -m csi1000.engine.daily_dashboard   # 不弹浏览器
```

## 行情数据

**主源 cjpy(天软)**,东方财富为回退。`update_market` 逐标的增量拼接,带三重保护:

| 保护 | 说明 |
|---|---|
| 重叠段校验 | 指数按 close 绝对差、ETF 按收益率差,容差 1e-3 |
| **尾部修订自愈** | 数据商当日收盘初值次日会修订(实测差 0.56%)。最近 ≤2 行不符、剔尾后重叠一致 → 判为修订,信任新数据替换;更早处不符仍拒写(保护存量) |
| 单标的容错 | 一个标的失败不中断全局 |

**为什么定在 16:30 而非 15:30**:15:30 拉到的是未定稿收盘价,曾导致 2026-07-29 全线口径不符卡死。

## 常见故障

| 症状 | 原因 | 处理 |
|---|---|---|
| 全线"口径不符,跳过" | 数据商修订了历史值 | 自愈机制已覆盖尾部修订;若更早处不符,人工核对后再决定 |
| launchd 退出码 78 | plist 里 Python 路径失效 | 检查 `/Library/Frameworks/Python.framework/Versions/3.11/bin/python3` 是否存在 |
| `NotImplementedError: StringDtype` | `data/cache/panels_*.pkl` 由不同 pandas 版本写入 | 直接删除,下次运行自动重建 |
| 面板数字与前一日对不上 | 数据被修订 or 重算口径变了 | 先跑复现检查:从存档重算须逐日复现原值 |

## 挖矿(重跑因子库)

```bash
export PYTHONPATH=src
python -m csi1000.engine.mine_ops26                              # 定稿库(close口径,约1小时)
python -m csi1000.engine.mine_open_horizons --h 1 --seed 42      # v5线(开盘口径)
python -m csi1000.engine.mine_xsec --h 1 --seed 42               # 截面叶子版
python -m csi1000.engine.eval_open_horizons --root mine_open     # 横向评估
```

**pod 部署**:`scripts/生产/pod_mine_open.sh`(tmux 常驻 + 分批并行 + 断点续跑)。
教训:pod 上 `nohup`/`setsid` 会被连带回收,**必须用 tmux**;容器 cgroup 内存上限可能远小于
`free` 显示值(实测 64G vs 显示 755G),并行度按 cgroup 实际上限定。

