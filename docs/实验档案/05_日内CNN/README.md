# 日内形态 1D-CNN 实验(判负,但发现真实的个股层日内效应)

日期:2026-08-02/03 · 脚本:`scripts/实验/日内CNN.py`(T1)、`日内CNN_T2.py`(T2a)、`日内CNN_T2b.py`(T2b)
数据脚本:`scripts/数据/拉日内_六指数.py`、`拉日内_个股.py`

## 动机与设计

问题:日线 OHLC 把一天 240 分钟压成 4 个数,日内形态信息被丢弃。CNN 的归纳偏置
(局部卷积 + 权重共享 + 池化)正对"可平移的形态检测",是处理该序列的正确架构。

**架构规格**(三轮实验共用):

| 层 | 设计 | 理由 |
|---|---|---|
| 输入 | (C=7, T=48) 5分钟bar | 归一化收益 / 绝对收益 / 累计路径 / 量占比 / 同时刻量能异常 / sin,cos时间编码 |
| | + 2 全局标量 | 波动状态 log(σ/σ20)、隔夜收益 |
| 卷积 | 三层膨胀卷积 d=1,2,4,k=5 | 感受野 29bar≈145分钟;膨胀而非降采样,保持时间分辨率 |
| 池化 | Avg + Max 双池化 | Max="今天出现过这形态吗"(平移不变),Avg="有多普遍" |
| 输出 | Dropout(0.3) → Linear → tanh | [-1,1] |
| 参数量 | **3,299** | 刻意做小,样本量是硬约束 |
| **损失** | **cos IC** | 与生产端因子加权同一把尺(吸取"两把尺反向"教训,见 02_截面叶子) |
| 协议 | walk-forward 逐年重训、**每折5种子**、验证集取训练期**时间末20%**、P&L判据 | |

**两个关键设计决定**:
1. **按当日波动归一化收益通道**——否则 CNN 学到的第一件事必然是"今天波动大",而那就是 rv1,基准里已有;
2. **直接喂 |r| 通道**——已知 rv1 是主力项(t=5.12),不该让模型从零学"取平方"。

## 三轮结果

| 实验 | 训练集 | 参数比 | 验证 cos IC | 指数 P&L(2021起) |
|---|---|---|---|---|
| **T1** | 6 指数,11,401 样本 | 3.5:1 | 0.006~0.21(**极不稳**) | 夏普 **0.00** |
| **T2a** | 150 只个股,268,708 样本 | **81:1** | **+0.054/+0.043/+0.055/+0.021/+0.022/+0.048** | −2.8% / 夏普 **−0.37** |
| **T2b** | 同上,预测值横截面聚合 | 81:1 | 市场级 cos IC **−0.001** | −0.8% / 夏普 **−0.27** |

T2b 分年 cos IC:2021 +0.102 / 2022 −0.036 / 2023 −0.003 / 2024 −0.006 / 2025 +0.063 / 2026 −0.017(六年两正)

## 结论

**✅ 真发现:个股层日内→次日效应是真的。**T2a 个股验证 cos IC 六年全正、均值 +0.04、
**种子标准差仅 ±0.004**——样本比上到 81:1 后,学到的东西稳定得不像噪声。
pooled 训练确实解决了样本量问题(对比 T1 的 ±0.055 剧烈波动)。

**❌ 但它不是市场择时信号。**两条路都堵死:直接迁移到指数 cos IC 掉到 +0.005;
横截面聚合后市场级 cos IC = −0.001。**该效应是特质性/截面性的,一平均就抵消。**

**❌ 掺入合奏的"夏普提升"是假的**——关键对照:

| 配置 | 年化 | 夏普 | 回撤 |
|---|---|---|---|
| 六库基线 | 21.7% | 1.07 | −20.0% |
| 六库×0.9 + CNN×0.1 | 21.1% | 1.12 | −18.1% |
| **六库×0.9 + 现金(纯降仓)** | 19.8% | **1.07** | **−18.1%** |
| 六库×0.7 + CNN×0.3 | 16.6% | **1.02** | −14.2% |
| 六库×0.7 + 现金 | 15.8% | **1.07** | −14.3% |

w=0.1 时略优于纯降仓,但 **w=0.3 时反而不如**——非单调 = 噪声特征。加上 CNN 独立夏普 −0.27、
测试期仅 5.5 年、项目已知种子噪音 ±2~4pp,不能算增量。

## 与项目其他发现的镜像关系

- **个股择时项目**证明:指数层可择时性**不可下沉**到成分股(个股 φ₁ 仅指数一半);
- **本实验**证明:个股层日内效应**不可上聚**到指数(cos IC 0.04 → 聚合后 −0.001)。

**两个层级有各自独立、互不传递的结构。**

## 过程中的两次自我纠错(方法论价值)

1. **拍平序列做线性回归是错的**(已作废):把 47 根 bar 拍成固定位置特征喂 Ridge/PLS,
   等于假设"第7根bar"是跨九年含义不变的变量,且线性形式表达不出 Σr²(已知的主力项)。
   用坏架构的失败推断 CNN 无望,是归纳偏置概念的误用。
2. **验证集横截面泄漏**(已修):首版把 6 指数按顺序拼接后取"数组末尾20%"当验证集,
   实为 kc50+hongli 全历史,与训练集同期 → 验证 cos IC 虚高至 0.53。修正为按**日期**
   划分后降到 0.21~0.006。首版 P&L(夏普0.62)随之作废。
