## 三、方法论沉淀(踩坑换来的检验标准)

这些规矩是实验事故的结晶,新想法进场前必须过:

1. **两把尺关卡**:新因子必须 ①独立成策净夏普 > 0 ②rank IC 与 cos IC **同向**。
   > IC 会骗人,P&L 不会。截面叶子的 t=−10 是"慢信号 × 月度堆叠 × 重叠Y"三重虚高的幻觉。

2. **钟速诊断(ρ / T)**:新变量先算有效样本 N_eff = W(1−ρ)/(1+ρ)。
   40 窗下 **N_eff < 10 的慢变量自动分流到状态层**,禁止进日频叶子堆。

3. **多种子强制**:项目已确认种子噪音 **±2~4pp/年**,与多数改进量级相当。
   **单库单跑的横向比较一律不作数。**

4. **"纯降仓"对照**:任何"掺入后夏普提升"必须与**同比例现金**对照。
   低相关 + 仍稀释 = 那是噪声不是正交 alpha。

5. **复现纪律**:从存档重算前,先证明能逐日复现原值,否则结论作废。
   (对照组必须逐位复现档案数字——这条抓出过验证集泄漏。)

6. **预注册判据**:实验开始前写死门槛,结果出来不改口径。
   截面叶子"主门槛未过但分年有暗线"就是靠这条守住的。
