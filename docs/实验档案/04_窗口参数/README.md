**结论:统一40窗从拍脑袋参数升级为有防御证据的定稿参数。**

用户提议:按信号日自相关ρ体系化定窗,W_i=clip(30(1+ρ)/(1−ρ),20,250),窗内有效样本恒定。
实验(h1/h5_s42 双库,ρ trailing2年逐季刷新,组合层40不动,对照复现档案头牌数字):

| | 固定40 | 自适应 |

| h5 | 37.0/1.64 | 29.4/1.34 |
| 双库合奏 | **32.1/1.51** | 27.0/1.28 |

**死因**:GP因子原始值多为趋势/水平型(水平AC1≈0.9+),公式把59~83%的因子推到250上限
→ 整库变成"一年区间排位"慢因子 → 与v1.2窗口单峰发现(40-50见顶,120已差)一致地劣化。
**误诊点**:水平AC1只适用于均值回复的状态变量(nhnl/skew120);对随机游走型因子输出,
排位有效性取决于"创新到达频率"而非水平持续性(价格ρ≈1但rank40(价格)完全有意义)。
统一40恰好匹配GP因子的创新钟速。

**保留价值**:①ρ诊断表(N_eff=W(1−ρ)/(1+ρ))进预检标准——慢变量(N_eff<10@40窗)自动
分流到状态层而非叶子层;②若做v6可换创新式速度度量(Δv的AC)重试,期望值低。
