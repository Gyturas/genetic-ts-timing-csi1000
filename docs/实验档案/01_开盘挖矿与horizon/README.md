# 开盘价挖矿 × 预测期限(h=1~7)实验档案

日期:2026-07-28 · 环境:RunPod 32核,python3.11 + pandas 3.0.5 · 代码:`mine_open_horizons.py` / `eval_open_horizons.py` / `scripts/pod_mine_open.sh`

## 实验设计

**挖矿目标(Y)全部用开盘价**:`Y = open[T+1+h] / open[T+1] − 1`
(T 收盘产生信号 → T+1 开盘建仓 → 持 h 日 → T+1+h 开盘结算。GA 适应度与治理记账两处同步替换;
A 股隔夜跳空频繁,旧 close 口径的 Y 含实盘吃不到的成分,本实验令挖矿、回测、实盘三口径完全一致。)

其余制度照抄 v4 定稿:26 算子、类库+专属双库、季度 walk-forward(2013 预热,2026-07-24 止)、
入库三关、黄牌退役。回测统一:v4 治理(cos IC 季权重 + 双40 + 同质参照 + 剔元老)、
**逐日调仓、open→open 结算、双边万5**,2018 起。

两轮:种子 42 挖 h=1~7 七库;种子 137 复验 h=1/2/5 三库(检验"七选一"的赢家诅咒)。

## 结论

1. **口径闭环免费**:h=1 开盘挖矿(27.0/1.25)≈ close 基线(26.9/1.25)。挖矿 Y 切换到开盘价零代价,自此三口径统一。
2. **种子噪音 ±2~4pp/年**,与多数 horizon 差异同量级 → **单库单跑的横向比较不作数,比较必须多种子**。
3. **h=5 两个种子都是第一**(37.0 / 29.8,均值 33.4)——结构真实;但幅度要按均值打折,且其优势集中于 2018–2020,近半程(2022 起)不再领先(种子137 后半夏普仅 0.90)。
4. **h=2 首轮 30.5 未复现**(26.9),出局;h≥6 明确衰减(h7 = 20.5/0.95),与"周频死亡谷"的频率回归衔接。
5. **推荐口径:h1+h5 四库合奏**(30.8%/1.47,后半 1.20,corr(h1合,h5合)=0.897)——比任何单库都稳,且零成本(信号取平均)。v5 候选:开盘 Y + 多种子合库;单一 h 单种子不定稿。
